# 遺物装備ガイド

Rust サーバー（Carbon / RelicAffix + RelicAppraisal）のプレイヤー向けガイドです。未鑑定の遺物で手に入る武器・防具・ツールの効果をまとめています。

- 公開ページ: https://gttq-henriy.github.io/rust-relic-guide/
- 元の文書: プラグイン側の `plugins/RelicAffix/Usage/player_guide.md`（このリポジトリには入っていません）

## 更新のしかた

`index.html` を直接編集して push すると、数十秒〜数分で公開ページに反映されます。

数値は RelicAffix v0.7.0 の既定値です。サーバーの設定を変えたらここも直してください。
